# EasyStaff API Module

Kotlin clients for the university's EasyStaff services, all on `gestioneorari.didattica.unimib.it`:

| API                   | Facade                | Spec                                  | What it covers                                                     |
|-----------------------|-----------------------|---------------------------------------|--------------------------------------------------------------------|
| Agenda Web, EasyBadge | `EasyStaffApi`        | `common/specs/easystaff-agenda`       | Lesson schedules, exam calendars, rooms, events, attendance        |
| Portale Planning      | `EasyStaffPlanningApi`| `common/specs/easystaff-planning`     | Appointment booking at the student information desks              |

Both are generated by `common/codegen` (see its README): files starting with `Generated by MyBicocca
codegen` are regenerated from the specs and must not be edited. The hand-written runtime is:

- `EasyStaffAbstractApi`, `EasyStaffRuntime` and `EasyStaffTypeConverters`: requests, JSON and dates
  of Agenda Web;
- `EasyStaffAttendanceRequests`: the presence certification request with the values EasyBadge expects;
- the `EasyStaffPlanning*` runtime files, and `EasyStaffPlanningHelpers` for building bookings.

## Agenda Web

No authentication is needed. Agenda Web is a PHP application, so the spec describes three kinds
of response:

- the options of its search forms, which `combo.php` declares as JSON assigned to script variables
  (`var elenco_corsi = [...];`): academic years, teachers, study programs, buildings, rooms;
- its searches (`grid_call.php`, `test_call.php`, `rooms_call.php`, `bookings_call.php`), form posts
  carrying the search form's fields and answering JSON;
- the room showcase (`index.php?view=vetrina_aule`), a page whose script assigns the rooms it
  shows to `window.data_to_show` as JSON, which its own PDF export reads. Its text is as the staff
  typed it, possibly blank or holding HTML.

```kotlin
val api = EasyStaffApi()
val year = api.core.getAcademicYears().values.maxOf { it.startYear }.toString()
val program = api.core.getStudyPrograms(year).first()

val week = api.schedule.getScheduleByProgram(
    academicYear = year,
    program = program.code,
    years = program.years.map { it.code },
    week = LocalDate.now(),
)
val rooms = api.buildings.getRoomDetails(buildings = listOf("U06")).values.flatMap { it.rooms }
api.close()
```

## Portale Planning

A JSON backend under `/portaleplanningAPI/api` behind the booking portals; every request names its
portal in the `X-CLIENTE` header. Reservations are provisional holds that must be confirmed within
the booking session, or deleted with `force`.

```kotlin
val desks = EasyStaffPlanningApi(EasyStaffPlanningPortal.INFORMATION_DESKS)
val services = desks.catalog.getServices()
```

## Tests

The tests call the live services and are tagged `live`; run the read-only ones by name:

```sh
./gradlew -p data-api :easystaff:test -PincludeLive --tests "*.EasyStaffAgendaApiTest"
```

`EasyStaffPlanningApiTest` includes a booking round-trip that holds and then deletes a slot.
