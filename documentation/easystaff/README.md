# EasyStaff Reverse Engineering

## Problem Statement

The **Università degli Studi di Milano-Bicocca** utilizes the **EasyStaff (Agenda Web)** platform to manage and publish critical academic logistics, including lecture schedules, exam dates, room availability, and university events. 
While this data is publicly accessible via a web interface, it lacks a structured, programmatic entry point for modern mobile integration.
To provide a seamless user experience within the **MyBicocca** Android application, there is a need for a robust, reverse-engineered API client that abstracts the complexities of the Agenda Web's web-scraped or parameter-driven data retrieval.
